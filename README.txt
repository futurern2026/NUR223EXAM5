NUR 223 Exam 5 — Complete Three-Day Study Arcade

Upload the contents of this ZIP to the ROOT of your GitHub Pages repository, keeping the day1, day2, and day3 folders intact.

The root index.html is the main site. Each day folder contains its own self-contained arcade.

Every game is linked directly from the main site, using a #game= deep link.

Progress is saved to localStorage per browser and website origin. It does not sync between devices.
